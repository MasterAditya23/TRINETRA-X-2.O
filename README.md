# TRINETRA X
AI-Based Intelligent Video Analytics Platform for Border Surveillance Using Existing CCTV Infrastructure. (SIH26187)

## Architecture
- `/vision` - Computer vision, YOLO object detection, and virtual fence logic.
- `/backend` - API, SQLite database, event processing, and reports.
- `/frontend` - React operator dashboard.
- `/data` - Local storage for SQLite DB, evidence snapshots, and demo videos.
- `/docs` - System documentation and API references.
